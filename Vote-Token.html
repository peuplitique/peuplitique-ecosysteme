Vision du Token Ressource

Le Token Ressource est l'identifiant de participation au sein de l'Écosystème Peuplitique.

Il permet aux citoyens de participer aux consultations, aux décisions collectives et aux futures formes de gouvernance partagée.

Fonctionnement

Chaque utilisateur dispose d'un identifiant unique.

Cet identifiant donne accès :

  • aux consultations citoyennes ;
  • aux espaces de participation ;
  • aux votes ;
  • aux projets collaboratifs ;
  • aux processus décisionnels de l'écosystème.

Exemple de Token

Accès aux décisions

Le Token Ressource constitue une clé d'accès à la participation citoyenne.

Les décisions et consultations sont opérées depuis l'application Peuplitique.

Consultations citoyennes

Le site présente les propositions et les informations publiques.

Les votes sécurisés, les consultations citoyennes et les décisions de gouvernance sont réalisés depuis l'Application Peuplitique.

Application Peuplitique

L'Application Peuplitique regroupe les consultations citoyennes, les votes sécurisés et les mécanismes de gouvernance participative.

Resource Token

The Resource Token is the participation identifier within the Peuplitique Ecosystem.

It provides access to consultations, decisions and governance processes.

Voting and decision-making functions are managed through the Peuplitique application.
